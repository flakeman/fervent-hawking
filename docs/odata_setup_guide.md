# Инструкция по включению OData в 1С:Предприятие

Стандартный интерфейс OData (REST API) в 1С:Предприятие не включается внутри конфигурации XML. Он требует публикации базы данных на веб-сервере (IIS или Apache) и программного разрешения доступа к объектам метаданных. 

Настройку необходимо выполнить на сервере/компьютере, где развернута ваша база 1С.

Ниже приведено пошаговое руководство, как это сделать.

---

## Шаг 1. Публикация базы данных на веб-сервере с поддержкой OData

Для того чтобы OData-интерфейс стал доступен, базу данных нужно опубликовать на веб-сервере IIS или Apache через **Конфигуратор**:

1. Запустите 1С:Предприятие в режиме **Конфигуратор** от имени Администратора.
2. Откройте меню **Администрирование** -> **Публикация на веб-сервере...**
3. В открывшемся окне:
   * Выберите имя публикации (например, `1c_db`).
   * Укажите веб-сервер (IIS или Apache) и каталог публикации (например, `C:\inetpub\wwwroot\1c_db`).
   * Перейдите на вкладку **HTTP-сервисы**.
   * Установите флажок **Публиковать стандартный интерфейс OData** (Publish standard OData interface).
   * Рекомендуется также включить флажок **Автозапуск** (для автоматического старта сессий).
4. Нажмите кнопку **Опубликовать** (Publish) и перезапустите веб-сервер при запросе.

> [!TIP]
> **Ручная настройка файла `default.vrd`**
>
> После публикации в каталоге публикации (например, `C:\inetpub\wwwroot\1c_db`) появится файл конфигурации веб-публикации **`default.vrd`**. Чтобы убедиться, что OData включен, откройте этот файл текстовым редактором и убедитесь, что секция `standardOdata` выглядит следующим образом:
>
> ```xml
> <standardOdata enable="true" reuseSessions="autouse">
>     <resheader name="Access-Control-Allow-Origin" value="*"/>
>     <resheader name="Access-Control-Allow-Headers" value="Authorization, Content-Type, Accept"/>
>     <resheader name="Access-Control-Allow-Methods" value="GET, POST, PUT, DELETE, PATCH, OPTIONS"/>
> </standardOdata>
> ```
> Параметр `reuseSessions="autouse"` оптимизирует производительность сессий, а заголовки CORS разрешают запросы от MCP-сервера.

## Шаг 2. Разрешение доступа к объектам метаданных через OData

По умолчанию в целях безопасности 1С закрывает доступ ко всем таблицам через OData. Чтобы разрешить чтение и запись справочников, документов и регистров, необходимо запустить специальный код в режиме **1С:Предприятие**.

### Скрипт для открытия доступа ко всем основным таблицам:
Запустите этот код (например, через внешнюю обработку или обработку «Групповое изменение реквизитов» -> Выполнить произвольный алгоритм):

```bsl
// Код для выполнения в 1С:Предприятие
Массив = Новый Массив;

// 1. Добавляем все Справочники
Для Каждого Метаданное Из Метаданные.Справочники Цикл
    Массив.Добавить(Метаданное);
КонецЦикла;

// 2. Добавляем все Документы
Для Каждого Метаданное Из Метаданные.Документы Цикл
    Массив.Добавить(Метаданное);
КонецЦикла;

// 3. Добавляем все Регистры Сведений
Для Каждого Метаданное Из Метаданные.РегистрыСведений Цикл
    Массив.Добавить(Метаданное);
КонецЦикла;

// 4. Добавляем все Регистры Накопления
Для Каждого Метаданное Из Метаданные.РегистрыНакопления Цикл
    Массив.Добавить(Метаданное);
КонецЦикла;

// Устанавливаем состав интерфейса OData
УстановитьСоставСтандартногоODataInterface(Массив);

Сообщить("OData успешно включен для " + Массив.Количество() + " объектов метаданных!");
```

> [!IMPORTANT]
> Если вы хотите открыть доступ только к определенным объектам (например, только к справочнику `Номенклатура` и документу `СписаниеЗапасов`), добавьте в массив только их:
> ```bsl
> Массив.Добавить(Метаданные.Справочники.Номенклатура);
> Массив.Добавить(Метаданные.Документы.СписаниеЗапасов);
> УстановитьСоставСтандартногоODataInterface(Массив);
> ```

## Шаг 3. Проверка работы OData-интерфейса

После выполнения первых двух шагов проверьте доступность REST API. Откройте в браузере или выполните GET-запрос по адресу:

```http
http://<ИП_ИЛИ_ХОСТ_СЕРВЕРА>/<ИМЯ_ПУБЛИКАЦИИ>/odata/standard.odata/$metadata
```
*Например:* `http://localhost/1c_db/odata/standard.odata/$metadata`

1. Введите имя пользователя 1С (с правами администратора или правом "Стандартный интерфейс OData") и пароль.
2. В ответе вы должны увидеть большой XML-документ со структурой базы данных (метаданными).

---

## Шаг 4. Настройка MCP-сервера для работы с вашей базой

Как только OData заработает, обновите настройки подключения в конфигурационном файле MCP.
Замените значения переменных среды в секции `1c-helper`:
* `1C_ODATA_URL`: Укажите рабочий адрес вашей публикации (обязательно заканчивающийся на `/`).
* `1C_ODATA_USER`: Логин пользователя 1С.
* `1C_ODATA_PASSWORD`: Пароль пользователя 1С.
* `1C_INDEX_FILE`: Абсолютный путь к файлу `1c_compact_index.json` в рабочей директории.
