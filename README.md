# 1C Project Workspace & AI Assistant Setup

Этот репозиторий содержит наработки для интеграции среды разработки **Codex / Gemini Agent** с базой данных 1С:Предприятие с использованием статического анализа метаданных и динамического OData REST API.

Вы можете скопировать эти наработки своему коллеге или запушить репозиторий в GitHub, чтобы развернуть аналогичное окружение на другой машине.

---

## Структура репозитория

* `/mcp/mcp_1c_helper.py` — Python-скрипт MCP-сервера (Model Context Protocol), предоставляющий инструменты для выполнения запросов OData к 1С, парсинга XML конфигурации и поиска по компактному индексу метаданных.
* `/mcp/mcp_config_example.json` — Пример файла конфигурации для регистрации MCP-сервера в среде Codex / Gemini.
* `/scripts/build_1c_index.py` — Скрипт для автоматического построения компактного индекса метаданных по выгруженной в XML конфигурации 1С.
* `/data/1c_compact_index.json` — Скомпилированный компактный индекс метаданных (справочники, документы, регистры сведений и накопления) для быстрого поиска объектов ИИ-ассистентом.
* `/docs/SKILL.md` — Системное руководство по стандартам разработки, правилам написания 1С-запросов и принципам работы с OData для ИИ-ассистента.
* `/docs/odata_setup_guide.md` — Пошаговое руководство по включению и настройке OData REST API на стороне веб-сервера и платформы 1С.

## Инструкция по установке для коллеги

### 1. Склонировать репозиторий
Склонируйте этот репозиторий в рабочую папку в среде Codex.

### 2. Собрать или обновить индекс метаданных (опционально)
Если конфигурация изменилась или вы хотите пересобрать индекс по локальной XML-выгрузке базы данных (например, лежащей в `C:\Users\...\Desktop\1C_tester`), выполните команду:
```bash
# Установите путь к папке с выгрузкой в переменную окружения или запустите напрямую
set 1C_CONFIG_DIR=C:\путь_к_вашей_выгрузке\1C_tester
python scripts/build_1c_index.py
```
Индекс будет обновлен в папке `/data/1c_compact_index.json`.

### 3. Зарегистрировать MCP-сервер в Codex / Gemini
Откройте файл конфигурации MCP-серверов в вашей среде (обычно это `mcp_config.json` в корневой папке настроек ассистента или `~/.code-settings/mcp_config.json`) и добавьте в него секцию `1c-helper`, указав абсолютные пути к файлам репозитория:

```json
{
  "mcpServers": {
    "1c-helper": {
      "command": "python",
      "args": [
        "C:/путь_к_репозиторию/mcp/mcp_1c_helper.py"
      ],
      "env": {
        "1C_ODATA_URL": "http://localhost/1c_db/odata/standard.odata/",
        "1C_ODATA_USER": "Administrator",
        "1C_ODATA_PASSWORD": "",
        "1C_INDEX_FILE": "C:/путь_к_репозиторию/data/1c_compact_index.json"
      }
    }
  }
}
```

### 4. Включить OData в 1С
Чтобы ИИ-ассистент мог читать и записывать реальные данные из вашей базы 1С, следуйте инструкциям в документе:
👉 **[docs/odata_setup_guide.md](docs/odata_setup_guide.md)**

## Использование ИИ-ассистентом
После подключения MCP-сервера ваш ИИ-ассистент получит доступ к следующим инструментам:
* `odata_query` — выполнение GET-запросов к 1С OData (выборка справочников, документов и движений с фильтрами).
* `odata_create` / `odata_update` — добавление и обновление данных в 1С через REST API.
* `search_compact_index` — мгновенный локальный поиск таблиц по ключевым словам (например, найти все регистры накопления по слову "Запасы").
* `extract_xml_query` — быстрое извлечение текстов запросов из XML-схем СКД (Template.xml).
