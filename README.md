# 1C:Enterprise MCP Server for AI Assistants (Codex / Gemini / Cursor)

Этот репозиторий содержит готовую интеграцию для среды разработки **Codex** (или любого другого клиента с поддержкой протокола MCP, например Gemini Agent / Cursor / Windsurf), позволяющую искусственному интеллекту глубоко анализировать конфигурацию 1С:Предприятие и взаимодействовать с живыми данными через OData REST API.

---

## 🌟 Возможности интеграции

1. **Гибридный поиск по метаданным**:
   * **Локальный компактный индекс**: ИИ мгновенно ищет любые таблицы (справочники, документы, регистры сведений и накопления) в памяти без обращений к диску или сети.
   * **Статический поиск в XML**: Поиск файлов объектов в распакованной выгрузке конфигурации 1С для анализа модулей объектов и форм.
2. **Динамический доступ через OData REST API**:
   * Инструменты для чтения (`odata_query`), создания (`odata_create`) и изменения (`odata_update`) записей 1С напрямую из чата с ИИ.
3. **Анализ запросов СКД**:
   * Извлечение текстов SQL-подобных запросов 1С прямо из схем компоновки данных XML (`Template.xml`).
4. **Стандарты и лучшие практики**:
   * Специально разработанный файл правил `SKILL.md` обучает ИИ оптимизировать запросы под СУБД (использование `ВЫРАЗИТЬ` для составных типов, фильтрация в параметрах виртуальных таблиц вместо `ГДЕ` и т.д.).

## 🛠️ Руководство по установке и настройке

### Шаг 1. Клонирование репозитория
Склонируйте этот репозиторий в удобную папку на вашей машине:
```bash
git clone https://github.com/flakeman/fervent-hawking.git
```

### Шаг 2. Регистрация MCP-сервера в вашей среде ИИ
Откройте файл конфигурации MCP-серверов вашего клиента (для ассистента Gemini это `mcp_config.json`, обычно расположенный в директории настроек вашего профиля).

Добавьте следующую конфигурацию в блок `mcpServers`, заменив `[PATH_TO_WORKSPACE]` на реальный абсолютный путь к склонированному репозиторию:

```json
{
  "mcpServers": {
    "1c-helper": {
      "command": "python",
      "args": [
        "[PATH_TO_WORKSPACE]/mcp/mcp_1c_helper.py"
      ],
      "env": {
        "1C_ODATA_URL": "http://localhost/1c_db/odata/standard.odata/",
        "1C_ODATA_USER": "Administrator",
        "1C_ODATA_PASSWORD": "",
        "1C_INDEX_FILE": "[PATH_TO_WORKSPACE]/data/1c_compact_index.json"
      }
    }
  }
}
```

> [!NOTE]
> * **Python 3**: Для работы сервера на компьютере должен быть установлен Python 3.
> * **Без внешних зависимостей**: Сервер написан с использованием стандартных библиотек Python (`urllib`, `json`), поэтому устанавливать дополнительные пакеты через `pip` не требуется.

### Шаг 3. Включение OData на стороне 1С
Для того чтобы ИИ-ассистент мог выполнять динамические запросы к данным, выполните инструкции по публикации базы на веб-сервере и программному открытию доступа к метаданным:
👉 **[Читать подробное руководство по OData](docs/odata_setup_guide.md)**

## 🔍 Описание инструментов (MCP Tools)

После запуска ассистент получит следующие инструменты:

| Название инструмента | Описание | Параметры |
| :--- | :--- | :--- |
| `search_compact_index` | Мгновенный поиск таблиц в памяти по ключевому слову. | `query` (слово для поиска) |
| `odata_query` | Выборка данных из таблиц 1С через HTTP GET-запросы с фильтрами и сортировкой. | `endpoint` (имя таблицы, например `Catalog_Номенклатура`), `filter` (OData-фильтр), `select` (поля), `top` (лимит записей) |
| `odata_create` | Создание новых записей или документов в 1С через POST-запрос. | `endpoint`, `data` (JSON-структура полей) |
| `odata_update` | Обновление существующей записи по ее GUID через PATCH-запрос. | `endpoint`, `ref_key` (GUID), `data` (JSON-структура изменений) |
| `search_config_metadata` | Поиск файлов метаданных в локальном XML-дампе конфигурации. | `config_dir`, `query` |
| `extract_xml_query` | Парсинг XML-файла схемы СКД (`Template.xml`) и извлечение чистого текста запроса 1С. | `template_path` |

## 💡 Примеры запросов, которые можно задавать ИИ

Благодаря интеграции вы можете общаться с ассистентом на естественном языке:
* *«Найди мне все справочники и регистры, в названии которых есть слово "Запасы"»* (ИИ использует `search_compact_index`).
* *«Выведи 10 первых документов СписаниеЗапасов через OData»* (ИИ использует `odata_query` к `Document_СписаниеЗапасов`).
* *«Найди в выгрузке 1C_tester макеты СКД и вытащи оттуда текст запроса»* (ИИ использует `extract_xml_query`).
* *«Напиши запрос для получения остатков номенклатуры с учетом правил оптимизации базы данных»* (ИИ обращается к `SKILL.md` и пишет запрос с фильтрацией внутри параметров виртуальной таблицы).
